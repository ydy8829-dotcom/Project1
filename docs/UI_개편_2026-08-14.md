# UI 개편 기록

## 변경 내용

사용자 관점에서 불필요한 개발·운영 상태 정보를 메인 화면에서 제거했다.

- API 상태 metric 제거
- 전체 문서 수 metric 제거
- 생성 모델 연결 상태 metric 제거
- 검색 방식 상태 metric 제거
- 서비스 상태 JSON 상세 expander 제거

## 유지한 기능

- 기술 질문 입력
- 예시 질문 선택
- 문서 근거 기반 답변
- 신뢰도
- 출처 URL과 인용 근거
- Reranker·검색 점수 등 근거 메타데이터
- 최근 질의 기록

## 문서 수의 의미

기존 `documents: 15`는 현재 `data/metadata/documents.jsonl`에 적재된 공식 seed 문서 레코드가 15개라는 뜻이다. PDF 페이지 수, 원문 파일 수, 비공개 매뉴얼 수를 의미하지 않는다. 실제 Service Manual·Maintenance Manual을 추가 적재하면 이 값은 증가한다.

## 검증

API 상태와 모델 연결 정보는 내부 `/health` API에서 계속 제공하지만, 일반 사용자용 UI에는 표시하지 않는다. 장애가 발생하면 질의 실행 시 오류 메시지로 안내한다.
