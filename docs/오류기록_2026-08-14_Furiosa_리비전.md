# Furiosa-LLM 리비전 호환성 오류

## 증상

Chat Playground 가상환경의 Furiosa-LLM으로 Qwen3 실행을 시도했으나 다음 오류가 발생했다.

```text
Revision Not Found: .../furiosa_config.json
Invalid rev id: v2026.1
```

## 원인

해당 가상환경의 Furiosa-LLM은 모델 리비전 `v2026.1`을 요청하지만 현재 Qwen3-8B-FP8 저장소에서 해당 리비전을 찾지 못했다. 따라서 모델 로딩이 시작되지 않았다.

## 추가 오류

서버 기동 로그 예시인 `Total size of parameters loaded`, `Application startup complete`, `Uvicorn running ...`을 셸에 직접 입력해 `command not found`가 발생했다. 이 문장들은 입력 명령이 아니라 서버가 성공했을 때 화면에 표시되는 로그다.

## 다음 조치

서버에 설치된 Furiosa-LLM 실행 파일과 버전을 먼저 찾고, Qwen3 모델과 호환되는 최신 실행환경을 선택한다. 모델 서버가 실제로 `Uvicorn running`을 출력하기 전에는 SSH 터널을 연결하지 않는다.
