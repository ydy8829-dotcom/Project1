# 오류 기록: NPU·GPU 비교 조건 불일치

## 발견 내용

GPU 결과가 추가되었으나 NPU와 GPU의 모델 양자화·실행 경로·장치 수가 서로 달랐다.

## 영향

측정값 자체를 폐기할 필요는 없지만, 동일 조건의 순수 하드웨어 비교로 단정할 수 없다. 현재 결과는 실행 구성 비교 참고자료로 분류한다.

## 조치

- GPU 벤치마크 질문이 UTF-8 정상 문자열인지 확인
- NPU·GPU 비교 한계와 정확한 PPT 표현을 별도 기록
- 재측정 전까지 GPU 결과에 조건 차이 주석을 표시

## 재발 방지

모델명·양자화·장치 수·실행 경로·질문 목록·`max_tokens`를 결과 JSON에 함께 저장하고, 비교표 작성 전에 조건을 검토한다.
