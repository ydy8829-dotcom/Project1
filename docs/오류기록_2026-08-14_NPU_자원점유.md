# NPU 자원 점유로 인한 Qwen3 기동 대기

## 확인 결과

`furiosa-smi ps`에서 다음 프로세스가 npu0~npu7 전체를 사용 중이다.

```text
PID 3388533
furiosa-apps/chat-playground
furiosa-ai/EXAONE-4.0-32B-FP8
port 8000
```

## 영향

Qwen3-8B-FP8 서버를 새로 기동할 NPU 자원이 없다. 또한 해당 프로세스가 공동 서버의 다른 실습일 수 있으므로 임의 종료하지 않는다.

## 다음 조치

프로세스 소유자와 사용 목적을 확인한 뒤, 사용자가 종료 권한을 확인한 경우에만 Chat Playground를 종료한다. 이후 Furiosa가 정상 동작하는 전용 가상환경의 `furiosa-llm`으로 Qwen3를 기동하고, `torchvision` 호환성 문제를 피한다.
