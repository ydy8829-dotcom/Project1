# 오류 기록: 한국어 질의에 영어 답변 반환

## 발생 상황

최종 Qwen3 + Reranker 질의 검증에서 한국어 질문에 대해 문서 근거는 정확했지만 답변 본문이 영어로 반환됐다.

## 원인

Qwen3 서버가 `/no_think`와 일반 언어 지시를 처리했지만, 한국어 출력 요구를 충분히 강하게 따르지 않았다.

## 조치

생성 프롬프트에 한국어 질의 감지 시 제목·본문·출처 문구를 포함한 전체 답변을 한국어로 작성하도록 명시하고, 숨은 추론 태그를 출력하지 않도록 강화했다.

## 검증 기준

- `<think>` 태그가 최종 API 응답에 노출되지 않아야 한다.
- 한국어 질문의 설명 문장이 영어로만 반환되지 않아야 한다.
- 문서 출처 URL과 근거 범위는 그대로 유지해야 한다.
