# Reranker 검증 메타데이터 보완 기록

## 증상

Reranker 적용 후 `Selective Etch Product Family`가 검색 결과 1위로 올라왔지만, API의 `evidence` 응답에는 `rerank_score`와 `retriever`가 표시되지 않았다.

## 원인

reranker가 내부 검색 결과에 점수와 처리 주체를 추가했지만, 최종 답변을 만드는 `evidence_view`가 제목·출처·인용문만 남기고 나머지 검색 메타데이터를 버리고 있었다.

## 조치

- `reranker`, `rerank_score`, `hybrid_score`, `bm25_score`, `vector_score`를 evidence 응답에 보존하도록 수정했다.
- retrieval method를 `bm25+tfidf-cosine+reranker` 또는 `bm25+embedding-cosine+reranker`로 표시하도록 수정했다.

## 검증 기준

FastAPI 재시작 후 동일 질문을 실행해 evidence 항목에 다음이 포함되는지 확인한다.

```json
"retriever": "furiosa-reranker",
"rerank_score": 숫자
```
