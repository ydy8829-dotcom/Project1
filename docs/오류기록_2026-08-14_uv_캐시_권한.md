# 오류 기록: uv 전역 캐시 권한 오류

## 발생 상황

50문항 평가를 실행할 때 `uv`가 사용자 전역 캐시(`C:\Users\ydy00\AppData\Local\uv\cache`)를 초기화하지 못하고 액세스 거부 오류를 반환했다.

## 원인

프로젝트 코드나 평가 로직이 아니라 전역 캐시 디렉터리의 Windows 권한 문제다.

## 조치

프로젝트 내부 캐시를 사용하도록 다음 방식으로 실행했다.

```powershell
uv run --cache-dir .uv-cache --with-requirements requirements.txt python scripts\evaluate_retrieval.py --evaluate-only
```

## 결과

평가가 정상 완료되었고 기준선 지표가 저장되었다.

## 재발 방지

프로젝트 실행·평가 명령에서는 전역 캐시 대신 `.uv-cache`를 우선 사용한다.
