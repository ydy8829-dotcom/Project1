# 오류 기록: Reranker 평가 중 이전 Embedding 환경변수 잔존

## 발생 상황

Reranker 평가 명령 실행 중 종료된 Embedding 서버(`18003`)에 요청이 전송되어 `WinError 10054` 연결 강제 종료가 발생했다.

## 원인

PowerShell은 같은 창에서 설정한 환경변수를 계속 유지한다. 이전 Embedding 평가에서 설정한 `FURIOSA_EMBED_BASE_URL=http://127.0.0.1:18003/v1`가 남아 있어, Embedding 서버를 종료한 뒤에도 평가 스크립트가 Embedding API를 호출했다.

## 조치

Reranker 평가 전 Embedding 관련 환경변수를 빈 문자열로 명시적으로 초기화한다.

```powershell
$env:FURIOSA_EMBED_BASE_URL=""
$env:FURIOSA_EMBED_MODEL=""
```

## 재발 방지

Embedding·Reranker를 교체할 때마다 사용하지 않는 모델의 환경변수를 반드시 빈 문자열로 초기화한다. 평가 스크립트는 활성화된 API만 호출한다.
