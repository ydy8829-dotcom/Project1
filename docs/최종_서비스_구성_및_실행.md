# 최종 서비스 구성 및 실행

## 최종 구성

```text
사용자
  -> Streamlit UI
  -> FastAPI 8002
       -> BM25 + TF-IDF 후보 검색
       -> Qwen3-Reranker-0.6B 재순위화
       -> Qwen3-8B-FP8 문서 근거 답변 생성
  -> 출처·인용·신뢰도·불충분 근거 표시
```

## NPU 배치

- Qwen3 생성: npu4~npu7
- Reranker: npu1
- npu0: 다른 사용자 프로세스가 사용 중일 수 있으므로 사용하지 않음
- Embedding: 별도 비교 실험 시 npu1에서 Reranker와 교체 실행

## 로컬 터널

```powershell
ssh -N -L 18001:127.0.0.1:8001 furiosa
ssh -N -L 18004:127.0.0.1:8004 furiosa
```

## 최종 FastAPI 실행

프로젝트 폴더에서:

```powershell
.\scripts\start_final_api.ps1
```

정상 상태 확인:

```powershell
curl.exe http://127.0.0.1:8002/health
```

예상 핵심 값:

```json
{
  "furiosa_configured": true,
  "furiosa_model": "furiosa-ai/Qwen3-8B-FP8",
  "embedding_configured": false,
  "reranker_configured": true,
  "reranker_model": "furiosa-ai/Qwen3-Reranker-0.6B"
}
```

## 검증 질의

```powershell
$body = @{ question = "Lam Research의 selective etch는 GAA에 어떻게 적용되는가?"; top_k = 5 } | ConvertTo-Json
Invoke-RestMethod -Uri "http://127.0.0.1:8002/api/v1/query" -Method Post -ContentType "application/json" -Body $body | ConvertTo-Json -Depth 10
```
