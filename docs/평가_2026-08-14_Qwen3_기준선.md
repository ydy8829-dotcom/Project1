# 2026-08-14 Qwen3 연결 상태 50문항 기준선 평가

## 평가 목적

Embedding과 Reranker 적용 전 현재 검색 파이프라인의 기준 성능을 확보한다. 이후 각 기능을 연결한 뒤 동일한 50문항으로 재평가하여 개선 효과를 비교한다.

## 실행 환경

- 생성 모델: `furiosa-ai/Qwen3-8B-FP8`
- API: FastAPI `http://127.0.0.1:8002`
- 현재 검색 방식: BM25 + TF-IDF cosine
- 평가 문항 수: 50문항
- 평가 상태: 합성 seed 데이터이며 도메인 전문가 검토 필요
- 실행 명령: `uv run --cache-dir .uv-cache --with-requirements requirements.txt python scripts/evaluate_retrieval.py --evaluate-only`

## 결과

| 지표 | 결과 |
|---|---:|
| Top-1 정확도 | 6% |
| Top-3 정확도/Recall@3 | 38% |
| MRR | 0.2919 |
| 평균 nDCG@3 | 0.2406 |

## 로컬 코드 검증

- `python -m compileall -q app scripts tests`: 통과
- `pytest`: 4개 테스트 통과
- 경고: Starlette의 `httpx` 호환성 관련 deprecation warning 1건. 현재 기능 실패는 아니며 추후 의존성 정리 대상으로 기록한다.

## 해석

현재 기준선은 프로젝트 목표인 Top-3 80% 이상에 미달한다. 다만 이 평가는 검색 문서 순위만 측정하며, 평가셋의 정답 문서 라벨도 합성 seed이므로 최종 성능으로 확정하지 않는다. 실제 고객 질의와 도메인 전문가가 검토한 관련 문서를 반영한 평가셋으로 다시 측정해야 한다.

## 다음 비교 실험

1. 현재 BM25 + TF-IDF 기준선 저장
2. Embedding 연결 후 동일 50문항 재평가
3. Reranker 연결 후 동일 50문항 재평가
4. Top-1, Top-3, MRR, nDCG@3 및 대표 질의 순위 변화를 비교

## Embedding 적용 결과

Embedding 서버(`furiosa-ai/Qwen3-Embedding-0.6B`)를 npu1에서 실행하고 동일한 50문항을 재평가했다.

| 지표 | 기준선 | Embedding 적용 | 변화 |
|---|---:|---:|---:|
| Top-1 정확도 | 6% | 18% | +12%p |
| Top-3 정확도/Recall@3 | 38% | 68% | +30%p |
| MRR | 0.2919 | 0.4242 | +0.1323 |
| 평균 nDCG@3 | 0.2406 | 0.4427 | +0.2021 |

- 검색 방식: `bm25+embedding-cosine`
- `embedding_configured`: `true`
- `reranker_configured`: `false`
- 평가셋 상태: 합성 seed 데이터이며 도메인 전문가 검토 필요

### 해석

Embedding은 모델명·약어가 변형되거나 표현이 달라지는 질의에서 의미 유사도 신호를 추가하여 Top-3 검색 성능을 38%에서 68%로 높였다. 그러나 목표 80%에는 아직 12%p 미달하며, Reranker 적용과 실제 도메인 평가셋 검토가 필요하다.

## Reranker 적용 결과

Reranker 서버(`furiosa-ai/Qwen3-Reranker-0.6B`)를 npu1에서 실행하고 동일한 50문항을 재평가했다. Embedding은 종료한 상태에서 BM25+TF-IDF 후보를 Reranker가 재순위화했다.

| 지표 | 기준선 | Embedding | Reranker | Reranker 기준 개선폭 |
|---|---:|---:|---:|---:|
| Top-1 정확도 | 6% | 18% | 90% | +84%p |
| Top-3 정확도/Recall@3 | 38% | 68% | 92% | +54%p |
| MRR | 0.2919 | 0.4242 | 0.9117 | +0.6198 |
| 평균 nDCG@3 | 0.2406 | 0.4427 | 0.8994 | +0.6588 |

- 검색 방식: `bm25+tfidf-cosine+reranker`
- `embedding_configured`: `false`
- `reranker_configured`: `true`
- 평가셋 상태: 합성 seed 데이터이며 도메인 전문가 검토 필요

### 해석

이번 평가에서는 Reranker 적용군의 Top-3가 92%로 프로젝트 목표 80%를 초과했다. 단, Embedding과 Reranker를 서로 다른 실험군으로 측정했으므로 두 효과를 단순히 합산할 수 없다. 최종 보고서에는 기준선·Embedding 단독·Reranker 단독 결과로 구분해 제시하고, 실제 도메인 검토 평가셋에서 재검증해야 한다.

## 실행 중 발생한 오류와 조치

- 전역 `uv` 캐시 접근 권한 오류가 발생했다.
- 프로젝트 내부 `.uv-cache`를 사용하도록 `--cache-dir .uv-cache`를 지정하여 우회했다.
- 평가 자체는 정상 완료되었으며, 이 오류는 코드 오류가 아니라 로컬 캐시 권한 문제다.
